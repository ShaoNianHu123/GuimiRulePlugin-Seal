# 诡秘之主 D20 规则 —— 海豹 (SealDice) 移植版

原 [GuimiRulePlugin](https://github.com/ShaoNianHu123/GuimiRulePlugin) (OlivOS/Python) 和 [GuimiRulePlugin-Dice](https://github.com/ShaoNianHu123/GuimiRulePlugin-Dice) (Dice!/Lua) 的海豹 (SealDice) JavaScript 移植版。

> ⚠️ 声明：本项目由 AI 辅助编程完成，使用前请自行测试。

## 指令列表

| 指令 | 功能 | 示例 |
|------|------|------|
| `.诡秘` | 生成 1 套 3.5 版属性（8项，2d3） | `.诡秘` `.诡秘5` |
| `.诡秘4.0` | 生成 1 套 4.0 预览版属性（9项） | `.诡秘4.0` `.诡秘4.0 3` |
| `.gm <目标>` | D20 技能/属性检定 | `.gm力量` `.gm格斗` |
| `.gmb <目标>` | 奖励投（2d20 取高） | `.gmb力量` |
| `.gmp <目标>` | 惩罚投（2d20 取低） | `.gmp格斗` |
| `.gmsc [成功损/失败损]` | 理智检定（SC） | `.gmsc` `.gmsc 1d2/1d4` |
| `.gmri` | 先攻检定（rd20 + 敏捷） | `.gmri` |
| `.gminit list/clr/del` | 先攻列表管理 | `.gminit list` `.gminit clr` |
| `.gmst <属性> [值]` | 录入/查看属性 | `.gmst 力量 5` `.gmst 幸运5` |

### 进阶用法

- **手动加值**：`.gm力量+2` `.gm格斗-1` `.gm格斗+2+3+4`
- **绝对指定**：`.gm力量5`（替换卡片值）
- **改判属性**：`.gm驯兽/教育`
- **奖励/惩罚投**：`.gm 优势 力量` `.gm 劣势 格斗`
- **批量录卡**：`.gmst 力量7体质6敏捷6魅力7灵感7意志6教育6幸运6理智16...`
- **查看属性**：`.gmst 力量`

### 判定规则

| 判定 | 条件 |
|------|------|
| 大成功 | rd20 = 20 |
| 大失败 | rd20 = 1 |
| SC 成功 | rd20 ≤ 理智 |
| 半疯 | 理智 ≤ 8 |
| 失控征兆 | 理智 ≤ 4 |
| 真疯 | 理智 ≤ 2 |
| 失控 | 理智 ≤ 0 |

## 安装

1. 将 `guimi_rule.js` 放入海豹的 `data/plugin/` 目录
2. 重启海豹或在 WebUI 中重载 JS
3. 在群内使用 `.ext GuimiRulePlugin on` 开启

## 可配置模板

在 WebUI「扩展功能 → JavaScript 插件 → GuimiRulePlugin」中可编辑 20 个回复模板。
