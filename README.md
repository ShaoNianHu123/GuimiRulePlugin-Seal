# 诡秘之主 D20 规则 —— 海豹 (SealDice) 移植版

原 [GuimiRulePlugin](https://github.com/ShaoNianHu123/GuimiRulePlugin) (OlivOS/Python) 和 [GuimiRulePlugin-Dice](https://github.com/ShaoNianHu123/GuimiRulePlugin-Dice) (Dice!/Lua) 的海豹 (SealDice) 移植版。

> ⚠️ 声明：本项目由 AI 辅助编程完成，使用前请自行测试。

## 功能

- 属性生成（2d3，范围 2~6）
- D20 技能/属性检定（rd20 + 属性 + 技能加值）
- 理智检定 (SC)
- 50+ 技能自动匹配关联属性
- 大成功/大失败判定
- 序列 & 消化度系统
- 位格与神性补正
